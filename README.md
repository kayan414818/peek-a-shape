# Peek-a-Shape｜立體探秘樂

A bilingual (繁體中文 / English) interactive 3D solid-shape learning platform for Hong Kong primary students.
三個自由選擇的模組：**立體模型庫（觀察）**、**展開圖魔法（展開）**、**切一刀看看（切割）**。

教學判斷（對錯）**全部由真實幾何計算決定**；提示層只負責用中／英雙語解釋，不會左右答案。

## 1. 技術方案（Tech Plan）

| 項目 | 選擇 | 原因 |
| --- | --- | --- |
| 3D 引擎 | Three.js r147（UMD，`lib/three.min.js`，傳統 `<script>` 載入） | 可離線、可直接用 `file://` 開啟，毋須安裝或建置 |
| 相機控制 | 自製環繞相機（拖動旋轉、滾輪／雙指縮放、自動旋轉） | 不依賴 OrbitControls 模組，載入更簡單 |
| 幾何核心 | 純 JavaScript（`geometry.js`／`clip.js`／`nets.js`），完全不依賴 THREE | 可在無瀏覽器環境做無頭測試 |
| 立體表示 | 全部化為多邊形網格（曲面亦細分：圓柱 96 段、圓錐 96 段、球 72×36） | 單一「半空間切割」演算法即可同時處理平面體與曲面體 |
| 截面判定 | 由幾何規則判定（`clip.classifySection`），非貼圖或假動畫 | 保證顯示的截面形狀幾何正確 |
| 介面 | `index.html` + `css/styles.css` + `js/{geometry,clip,nets,i18n,viewer,app}.js` | 純靜態，任何現代瀏覽器可跑 |
| 語言 | `i18n.js` 字典（132 個鍵，每個都有 zh/en），即時切換 | 全介面、題目、提示、回饋、名稱、解說、圖表標籤與錯誤訊息皆雙語；題目文字在畫面渲染時才組成本地化文字，切換語言即時更新 |

## 支援的立體（12 種）
cube 正方體、cuboid 長方體、triangular/quadrilateral/pentagonal/hexagonal prism 三/四/五/六角柱、
triangular/square/pentagonal pyramid 三/四/五角錐、cylinder 圓柱、cone 圓錐、sphere 球。

## 切割模式（模組三）
水平 horizontal、垂直 vertical、斜切 slant、對角 diagonal、自由角度 free（滑桿調角度 0–90°、自由模式可 0–360° 旋轉）。
另備：切割平面預覽、先預測再切、逐步模式（看平面 → 切開 → 兩塊分開）、重置、截面 2D「印章」抽取（可旋轉縮放）。

## 不支援 / 「此切法稍後開放 / This cutting mode is coming soon」
- 圓柱、圓錐被平面斜切同時又切到平底時，截面是「曲線＋直邊」的複合形（`composite`）。
  為避免顯示幾何上錯誤的截面，此組合會停用或標示「此切法稍後開放」，不會硬畫。
- 球體：只顯示「球體無法完全攤平成展開圖」的說明，不提供假展開圖。
- 自由手繪切割（用筆畫出切割面）列為 MVP 之後的項目。

## 模組功能
- **模組一 立體模型庫**：360° 旋轉、縮放（滾輪／雙指／按鈕）、可選自動旋轉；透視模式 X-Ray（一鍵半透明，棱藍、頂點黃）；
  高亮面（半透明淺綠）、棱（藍色線段）、頂點（黃色小圓點）；可點選數面並顯示「1, 2, 3… 共 N 個面」；名稱標籤與雙語小檔案。數量全部由幾何資料計算。
  圓柱＝2 個平底＋1 個曲面；圓錐＝1 個平底＋1 個曲面；球＝沒有平面；並會親切解釋棱／頂點為何不適用。
- **模組二 展開圖魔法**：各立體展開圖（球除外）；0–100% 連續摺合滑桿（真正連續，非兩格）；
  一鍵**自動摺合／自動展開**（按鈕會即時顯示百分比並跟隨動畫更新）；由立體攤平；雙向面對應發光；
  多於一種正方體展開圖；**展開圖配對考驗**（同時顯示多個展開圖選項，答對後系統即場播放動態摺合動畫驗證）；
  錯誤展開圖示範（面重疊／有縫隙）並給溫和提示。
- **模組三 切一刀看看**：真正的 3D 幾何切割成兩塊、正確截面、紫／粉高亮截面並附雙語名稱、
  截面 2D「印章」抽取（可旋轉縮放）、逐步模式、重置、先預測再切、切割平面預覽。

## 出題與判定
- **答錯兩次機制（三個問答部分一致）**：展開圖大考驗、切割大考驗、以及「先猜一猜」——
  第一次答錯**不揭示答案**，只給一則引導式提示（提示由幾何資料按規則生成），讓學生再試；
  第二次仍然答錯，才顯示正確答案＋解釋（為甚麼錯、為甚麼對）。已試錯的選項會淡化並鎖住。
  「先猜一猜」第一次猜錯時**不會切開**（避免用結果直接給答案），第二次才切開並揭示截面與解釋。
- **提示與解釋一律引用該立體自身的特徵**：每個立體都有一段特徵句（面數／棱數／頂點數、底面形狀、
  有沒有曲面），例如正方體「6 個相同的正方形面、12 條棱、8 個頂點」、圓柱「2 個圓形平面 + 1 個曲面」。
  展開圖題會用這些特徵對照展開圖的面數與形狀；切割題先講立體特徵，再按切法（水平／垂直／斜／對角）
  說明截面與底面、曲面的關係，揭示答案時再加上「截面邊界由 N 條邊圍成（或切到曲面）」的幾何理由。
- **答對也有解釋**：不論答對或答錯，回饋都用該立體的特徵（面／棱／頂點／曲面）加上幾何理由，
  解釋「為甚麼是這個答案」——展開圖會說明這個展開圖的面數如何跟立體的面一一對應；
  切割與「先猜一猜」會說明截面邊界由多少條邊圍成（或切到曲面），所以是這個形狀。
- **每題按「下一題」會直接出下一題**：答完（或目標挑戰中途放棄）按「下一題」即時生成新題目，
  不需要再按一次「大考驗」；新題一律由未切開的平面預覽開始。
- 展開圖大考驗兩種題型：配對（哪一個可摺成指定立體）、不能摺（哪一個不能摺成）。選項以小型 3D 展開圖呈現（可重用、避免 WebGL 外洩），
  答對／揭示後在舞台播放動態摺合動畫作驗證（答錯時另有「看正確答案的摺合動畫」）；干擾選項取自其他立體的真實展開圖或幾何上重疊／有縫隙的展開圖，全部由幾何規則判定。
- 切割三種題型：配對截面（match）、判斷截面（judge）、目標截面挑戰（target）。判定完全依據幾何規則／3D 計算。
  目標挑戰第一次做不到時給思考提示，第二次仍做不到就指出一個真正可行的切法（切法＋位置滑桿數值）。
- AI／提示層只解釋、給漸進提示，不猜測、不覆寫幾何。
- 未接外部 AI 時採用規則式雙語提示模板，且不會聲稱「即時 AI」。
- 頂欄只保留「主頁」與語言切換鈕；模組之間的切換一律經主頁自由選擇。

## 執行方式
直接用瀏覽器開啟 `index.html`（支援 `file://`），無需安裝或建置。

## 用 http://peekashape.com 開啟（本機專屬網址）
已在本機設定專屬網址 **http://peekashape.com**，可在 **Safari** 及 **Google Chrome** 直接開啟：
- `/etc/hosts` 加入 `127.0.0.1 peekashape.com`（只影響這台電腦）。
- `tools/serve.rb`（Ruby + WEBrick）在埠 80 提供本專案靜態檔案。
- 桌面「**Peek-a-Shape 連結**」資料夾內有：
  - `peekashape.com.webloc` — 雙擊以預設瀏覽器開啟。
  - `啟動並開啟網站.command` — 需要時先啟動伺服器，再開啟網站。
  - `用 Safari 開啟.command`、`用 Google Chrome 開啟.command` — 指定瀏覽器開啟。

> 伺服器是使用者程序，重新開機後只要雙擊任何一個 `.command`（或 `啟動並開啟網站.command`）便會自動重新啟動。
> 手動啟動：`ruby tools/serve.rb`；停止：`pkill -f tools/serve.rb`。
> 想完全移除本機網址設定：執行 `tools/uninstall-link.sh`。
>
> 註：macOS 隱私保護（TCC）不允許背景 LaunchAgent 讀取「桌面」檔案，因此採用「雙擊啟動」方式而非常駐服務。
> 若想讓它開機自動常駐，可把整個專案搬到非受保護位置（例如 `~/Sites/Peek-a-Shape`）後改用 LaunchAgent。

## 用手機／平板開啟（同一 Wi‑Fi）
伺服器綁定所有網路介面（`*:80`），所以同一 Wi‑Fi 下的 **iPhone、iPad、Android、其他電腦** 都能開啟。
- 桌面上有 **`用平板或手機開啟（顯示 QR 碼）.command`**：雙擊後會開啟 QR 碼頁面，用手機相機掃描即可進入。
- 亦可直接輸入網址：
  - `http://<這台 Mac 的 Wi‑Fi 位址>/`（例：`http://192.168.3.5/`）— 任何裝置皆可。
  - `http://peekashape.local/` — 已把本機 Bonjour 名稱設為 `peekashape`，Apple 裝置通常可直接解析。
- QR 頁面：`connect.html`（可加 `?ip=<位址>` 指定要顯示的 Wi‑Fi 位址）。
- 查詢目前位址：`ipconfig getifaddr en0`。

> 首次在 iPhone／iPad 開啟時，若連不上，請確認：兩部裝置在同一個 Wi‑Fi、Mac 沒有休眠、以及「系統設定 → 一般 → 共享」沒有關掉相關服務。
> 欲從**行動網路／外地**存取，需要公開通道（如 Cloudflare Tunnel）或部署到主機，非本機設定可達成。

- `tests/smoke.html` — 全 App 冒煙測試（65 項：三模組 × 12 立體、切法、三題型、展開圖按鈕百分比、主頁滿版、頂欄精簡、語言切換、DOM 事件）。

- 無頭（macOS，無需 Node）：`osascript -l JavaScript <腳本>`，載入 `geometry.js → clip.js → nets.js`（108 項）。
